Grau, Altura e Profundidade
Grau de um nó = número de filhos

Altura de um nó = maior número de arestas até uma folha abaixo dele

Profundidade = número de arestas da raiz até o nó

| Nó | Grau | Altura | Profundidade |
| -- | ---- | ------ | ------------ |
| a  | 2    | 3      | 0            |
| b  | 2    | 2      | 1            |
| c  | 2    | 1      | 1            |
| d  | 0    | 0      | 2            |
| e  | 2    | 1      | 2            |
| f  | 0    | 0      | 2            |
| g  | 0    | 0      | 2            |
| h  | 0    | 0      | 3            |
| i  | 0    | 0      | 3            |

| Caminho       | Comprimento |

| a → b → e → h | 3           |
| a → b → e → i | 3           |
